# W·HERE 隐私与安全边界

这份文档描述当前黑客松 Demo 的真实边界。它不是生产隐私政策，也不代表未来部署已经完成合规审查。

## 当前 Demo 规则

- 只使用项目预置的合成 Mei、Lin 和雨天内容；演示者不得输入真实悼念内容、真实姓名、联系方式、住址、照片、声音或其他敏感个人信息。
- 当前状态只保存在浏览器内存，刷新页面会重置；没有账号、数据库、跨设备同步或生产删除流程。
- 当前 AI 是确定性离线适配器，不调用真实模型，不把 Demo 输出描述成生产 AI。
- 当前认证凭证 `LOOP-DEMO` 是模拟凭证，不是身份认证方案。
- 默认触发策略是 `pull_only`；没有后台主动推送、悲伤检测、定位、传感器或随机触发。
- 接收者内容标记为 `recipient-authored`，不能回写为记录者生前事实。
- 原始内容和 AI 派生内容分开显示，派生内容带 AI 标记、来源 Context ID、Asset ID、生成模式和触发原因。

## 已验证的离线边界

当前 `src/` 中未发现以下运行时能力：

- `fetch` 或外部 API 调用；
- `localStorage`、IndexedDB 或 Cookie 持久化；
- geolocation、camera 或 microphone；
- 动态 HTML 注入；
- 必须存在的真实硬件设备。

这支持“离线软件 Demo”的描述，但不等于未来生产系统自动安全。

## 现场安全

- 只使用合成 Demo 数据，不让观众或评委输入真实个人经历。
- 演示前关闭包含私人聊天、邮箱、Token、GitHub 私有页面和本地路径的窗口。
- 投屏前检查浏览器地址栏、终端、通知、系统托盘和录屏范围。
- 视频、截图、立牌和日志不得包含私人数据、API Key、Cookie 或机器用户名。
- 不在 `.env`、README、视频脚本、截图或 Skill prompt 中写入秘密。
- 录制真实成员头像、声音或肖像前，必须获得明确同意并登记用途和撤销方式。

## 生产前未解决的问题

正式产品仍需单独设计并评审：账号和关系撤销、加密和密钥管理、备份和删除、真实音频/图片处理、模型供应商和日志脱敏、监护人/遗产争议、访问审计和 incident response。

这些问题不能用当前的 `LOOP-DEMO` 或内存状态伪装成已解决。
