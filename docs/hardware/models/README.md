## 打开与交付

- 建议使用 Rhino 7 或更高版本直接打开，以保留原始曲线、拉伸体、Brep、图层和文档公差。
- 需要提交 STEP、STL 或其他制造格式时，应从该源模型另行导出，并保留本文件作为可编辑母版。
- 当前仓库只确认文件完整性与基础几何信息；在加工或 3D 打印前，仍需检查闭合实体、壁厚、公差、材料、装配间隙与实际硬件尺寸。
- 模型用于说明「我在」硬件形态与 Hackathon 原型，不应仅凭仓库文件宣称已经完成量产验证。
