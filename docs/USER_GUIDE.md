# W·HERE 傻瓜式使用教程

这份教程面向第一次打开项目的人。按顺序操作即可，不需要后端、数据库、API Key 或真实硬件。

[返回 README](../README.md) · [查看产品理念](../05_PRODUCT_CONCEPT_W_HERE.md)

## 你将完成什么

完成教程后，你会走通下面这条产品闭环：

```text
Mei 为女儿 Lin 留下一段真实记忆
→ Mei 审核 AI 内容和使用边界
→ Lin 主动分享今天发生的事
→ W·HERE 用真实旧记忆回应今天
→ Lin 收藏一封有来源的远方回信
```

## 第一部分：把软件运行起来

### 第 1 步：确认电脑装有 Node.js

打开 PowerShell 或终端，输入：

```bash
node --version
npm --version
```

看到类似 `v20.x.x` 和 `10.x.x` 的版本号，就可以继续。

如果提示“找不到 node”或“不是内部或外部命令”，请先前往 [Node.js 官网](https://nodejs.org/) 安装 LTS 版本，然后重新打开终端。

### 第 2 步：下载项目

没有本地项目时，在终端依次输入：

```bash
git clone https://github.com/lavine888/HKhackthon-loop.git
cd HKhackthon-loop
```

如果项目已经位于电脑中，直接在终端进入该目录即可。

### 第 3 步：安装依赖

在项目目录输入：

```bash
npm install
```

第一次安装可能需要几分钟。结束后只要没有红色错误，就可以继续。

### 第 4 步：启动软件

输入：

```bash
npm run dev
```

终端出现 `Local: http://localhost:5173/` 后，不要关闭这个终端窗口。

### 第 5 步：打开页面

在浏览器地址栏输入：

```text
http://localhost:5173/#/
```

看到“我在 W·HERE”和“过去的记忆，回应现在的生活”，说明启动成功。

## 第二部分：30 秒快速体验

这条路线使用系统预置的雨天记忆，不需要先填写记录者表单。

### 第 1 步：进入接收者页面

1. 点击顶部的 **收到回应**。
2. 点击黑色按钮 **主动进入**。
3. 点击 **是留给我的，继续**。

### 第 2 步：分享今天发生的事

1. 保持内容类型为 **文字**。
2. 点击 **使用雨天 Demo 内容**。
3. 输入框会自动出现“今天下雨，我又忘记带伞了。”
4. 点击 **让过去的记忆回应现在**。

也可以切换到 **照片描述**，手动输入：

```text
下雨了，我站在公司门口，发现自己没有带伞。
```

当前版本使用照片文字描述，不会真的上传图片。

### 第 3 步：检查回应是否有来源

页面会展示三层内容：

| 区域 | 你会看到什么 |
| --- | --- |
| 今天 | Lin 刚刚输入的内容，标记为 `recipient-authored` |
| 真实原始来源 | Mei 本人留下的雨天叮嘱 |
| AI 生成 | 把今天与旧记忆连接起来的有限回应 |

向下查看 `Context ID`、`Asset ID`、生成模式和 `pull_only` 触发策略。它们证明回应来自哪段内容，以及哪部分是 AI 生成。

### 第 4 步：收藏远方回信

1. 点击 **收藏这封远方回信**。
2. 页面出现“今天与过去，都被好好放在这里”，说明纪念物已生成。
3. 在 **为今天再留一句话** 中输入任意内容。
4. 点击 **保存我的话**。

看到“已独立保存为接收者内容，不会成为记录者生前事实”，说明完整闭环已经完成。

## 第三部分：完整记录者流程

这条路线展示一段新记忆如何被记录、审核、授权，再进入接收者体验。

### 第 1 步：开始记录

1. 回到首页。
2. 点击顶部 **留下记忆**。
3. 点击 **Start a record**。

### 第 2 步：选择关系

在 **关系 / 接收者** 中选择：

```text
Lin · Mother and daughter
```

页面会显示 Subject、Recorder、Recipient 和 Buyer，方便确认这段内容属于谁、由谁留下、给谁查看。

### 第 3 步：填写原始素材

选择 **文字**，然后按下面示例填写：

| 字段 | 可直接使用的示例 |
| --- | --- |
| 原始内容 | 你从小就总忘带伞，淋湿了回去先把头发吹干，别着凉。 |
| 主题 | Rainy day reminder |
| 为什么重要 | 这是我一直想留给女儿的一句生活叮嘱。 |
| 使用场景 | 勾选“想念时” |

重要性权重和情绪信息可以保持默认值。比赛演示时建议勾选 **生成一条可逐项审核的 AI 摘要建议**，这样下一页能够展示所有者审核能力。

### 第 4 步：进入所有者审核

1. 点击 **进入所有者审核**。
2. 在 AI 建议卡片上点击 **批准**；也可以演示 **编辑**、**移除** 或 **拒绝**。
3. 检查原始素材仍单独显示，没有被 AI 内容覆盖。
4. 勾选 **我已审核原始素材、每条 AI 建议、情绪权重和关系范围**。
5. 点击 **保存已审核 Context**。

看到 `This moment has a place.`，说明记录已保存到当前浏览器内存。

### 第 5 步：用刚保存的内容生成回应

1. 点击顶部 **收到回应**。
2. 点击 **主动进入**。
3. 点击 **是留给我的，继续**。
4. 输入今天发生的事。
5. 点击 **让过去的记忆回应现在**。
6. 检查原始来源、AI 标记和 Context ID。
7. 点击 **收藏这封远方回信**。

此时回应会使用刚刚保存并审核过的新 Context，而不是预置内容。

## 第四部分：可选信物入口

硬件模拟器用于证明实体戒指、NFC、BLE 按钮或桌面物件可以作为入口，但它不是软件体验的必要条件。

1. 点击顶部 **信物入口**。
2. 点击 **Open simulator**。
3. 进入绑定页面，使用默认的 Mei、Lin 和 `LOOP-DEMO` 模拟凭证。
4. 完成绑定和托付。
5. 触发 `touch` 事件。
6. 如果设备被设为不可用，允许 software fallback 后仍可进入接收者流程。

未经验证的事件不会进入接收者页面。没有真实硬件时，直接使用 **收到回应** 即可完成核心 Demo。

## 第五部分：Echo Map Journey

在浏览器打开：

```text
http://localhost:5173/#/recipient/echo-map
```

这个页面提供更具仪式感的记忆节点体验，可以选择强度、检查提议、接受中性行动、查看来源、留下回应并点亮节点。任何阶段都可以跳过、停止或隐藏。

Echo Map 是展示层，不替代“接收者分享今天 → 真实记忆有限回应”的核心产品逻辑。

## 常见问题

### 页面刷新后刚才的数据不见了

这是当前 Offline MVP 的正常行为。所有状态保存在浏览器内存中，刷新会恢复预置 Demo。需要重新从 **留下记忆** 开始。

### 打不开 `localhost:5173`

确认运行 `npm run dev` 的终端仍然开着。如果端口被占用，Vite 会显示另一个地址，例如 `http://localhost:5174/`，请打开终端实际显示的地址。

### `npm install` 报错

先确认 Node.js 版本为 20 或更高，然后在项目目录重新执行：

```bash
npm install
```

如果网络受限，需要切换到可访问 npm 的网络环境。

### 为什么没有真的播放语音或上传照片

当前版本是比赛用软件闭环原型。语音和图片使用文字模拟，重点验证关系授权、来源追踪、有限回应和接收者控制权。

### AI 是不是在模仿离世者本人

不是。所有生成内容都明确标记为 AI，只能使用经过记录者审核和授权的来源，也不能新增重要事实、替用户做重大决定或进行自由人格聊天。

### 如何停止软件

回到运行 `npm run dev` 的终端，按 `Ctrl + C`。出现确认提示时输入 `Y` 并回车。

## 比赛演示建议

推荐用 2 分钟完成以下动作：

1. 用 20 秒说明 W·HERE 不是数字复活，而是“有来源的可回应记忆”。
2. 用 35 秒展示 Mei 留下雨天叮嘱，并批准 AI 建议与边界。
3. 用 15 秒切换到 Lin，强调接收者主动进入。
4. 用 25 秒输入“今天下雨，我又忘记带伞了”。
5. 用 20 秒展示原始来源、AI 标记和 Context ID。
6. 用 5 秒收藏远方回信，并以“过去的记忆，回应现在的生活”收尾。
