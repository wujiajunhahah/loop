# Project records / 项目记录

This directory preserves design decisions, risks, interface requests, audits, and task reports from the Hackathon development process.

本目录保存 Hackathon 开发过程中的设计决策、风险、接口请求、审计与任务报告。

## Legacy path map / 历史路径映射

Records written before the repository reorganization preserve the paths that were true when those reports were produced. Read them with this mapping:

| Historical path | Current path |
| --- | --- |
| `src/`, `ios/`, root `package.json` | `apps/software-mvp/` |
| `app/` | `apps/alloop-kit/` |
| `omi_simple/` | `apps/omi-simple/` |
| `visual-prototype/` | `apps/visual-prototype/` |
| `pigeon-backend/` | `services/pigeon-backend/` |
| `server/` | `services/local-relay/` |
| `pc/` | `tools/wearable-analysis/` |

Historical reports are intentionally not rewritten, so their recorded commands and file scopes remain faithful to the original work.
