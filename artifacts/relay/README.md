# Relay demo delivery archive / Relay 演示交付包

[`relay-package.zip`](./relay-package.zip) is the packaged Android relay demo retained from the Hackathon integration workflow. It contains a debug APK, a receiver server, and offline relay utilities.

`relay-package.zip` 是 Hackathon 联调流程中保留的 Android relay 演示交付包，其中包含 debug APK、接收服务与离线 relay 工具。

- This is a binary delivery artifact, not source used by the root build.
- The archive is approximately 74 MB; download it only when testing that relay path.
- Inspect the archive README and scripts before running them in a local environment.
- Do not treat the included debug APK as a production release.
