# Applications / 应用

User-facing clients and runnable product experiences are grouped here.

这里集中保存面向用户、设备或现场演示的可运行应用。

| Path | Role | Run |
| --- | --- | --- |
| [`visual-prototype/`](./visual-prototype/README.md) | High-fidelity creator experience and future recipient-view preview | `pnpm dev` |
| [`alloop-kit/`](./alloop-kit/README.zh-CN.md) | Flutter/BLE client using the Alloop ring SDK | `flutter run` |
| [`omi-simple/`](./omi-simple/README.md) | Omi voice-diary chunk forwarding client | `flutter run` |
| [`software-mvp/`](./software-mvp/README.md) | Relationship Agent, device contracts, simulator, and Capacitor iOS shell | `npm run dev` |

Each application owns its dependencies, environment example, and build output. Run package-manager commands from the selected application directory.
